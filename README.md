# Rock Paper Scissors

A console-based Rock Paper Scissors game written in C++.

## Features

- Rock, Paper, Scissors gameplay
- Input validation
- Case-insensitive commands
- Score tracking
- Replay option

## Requirements

- C++ compiler
- C++11 or newer

## Build

```bash
g++ main.cpp -o RockPaperScissors
```

## Run

Windows

```bash
RockPaperScissors.exe
```

Linux/macOS

```bash
./RockPaperScissors
```
