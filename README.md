# Rock Paper Scissors

A console-based Rock Paper Scissors game written in modern C++.

## Features

- Case-insensitive input
- Robust input validation
- Best-of-N match system
- Score tracking
- Replay support

## Preview



## Getting Started

### Requirements

- C++11 or newer
- g++

### Build

```bash
g++ src/main.cpp -o RockPaperScissors
```

### Run

Windows

```bash
RockPaperScissors.exe
```

Linux/macOS

```bash
./RockPaperScissors
```

```

    main.cpp
```
